라벨링 시작하기

  1. ‘전체 자동 초안 만들기’를 실행합니다. 원형·여러 카메라의 위치 후보에서 공의 마스크와 박스를 자동 생성합니다. 저장한 라벨은 덮어쓰지 않으며 중단 후 이어갈 수 있습니다.
  2. 왼쪽에서 촬영을 고르고, 컬러 또는 모노 카메라를 선택합니다. 자동 초안은 아직 검수 전입니다.
  3. ‘클릭 분할(S)’에서 공 내부를 클릭합니다. 윤곽을 확인하고 Enter로 추가합니다. Shift+클릭은 주변을 제외하고 추가 클릭은 공 영역을 포함합니다. 수동 박스(B)도 사용할 수 있습니다.
  4. ‘공 후보 찾기’는 원형 후보, ‘이전 라벨 가져오기’는 같은 카메라의 이전 작업을 제안합니다. 실제 공인 제안만 클릭해 추가하세요. ‘수정(V)’에서 박스를 옮기거나 모서리를 조절합니다. 가려진 공은 보이는 부분 기준으로 표시하고 ‘가림 있음’을 체크합니다.
  5. ‘수동 윤곽(P)’은 공 둘레를 클릭해 직접 분할합니다. Enter로 닫고 다시 Enter로 반영합니다. 선택한 기존 공은 ‘선택 공 클릭 분할로 보정’으로 수정할 수 있습니다.
  6. 프레임 안의 공을 모두 표시했으면 ‘검수 완료’를 누릅니다. 공이 없으면 ‘공 없는 프레임으로 완료’를 누릅니다. N으로 다음 미검수 초안을 확인합니다.
  7. 촬영별 분할을 지정한 뒤 내보냅니다. 원본 크기의 PNG, COCO·YOLO 라벨과 선택한 공의 잘라낸 이미지가 생성됩니다. 클릭 분할로 만든 윤곽은 COCO에 함께 저장됩니다.

자동 제안은 추가 후에도 검수 전 초안입니다. 박스를 수정하면 검수 완료가 해제되고 해당 박스의 기존 분할 윤곽은 제거됩니다. 보기 밝기는 표시만 바꾸며 학습 이미지는 원본 밝기로 저장됩니다. 잘라낸 공은 양성 예시이며, 별도 분류기를 학습할 때에는 공이 아닌 예시도 준비해야 합니다.

약 30장으로 표시 기준을 먼저 맞춘 후 학습용 데이터를 늘려가세요. 같은 촬영의 인접 프레임은 많이 모으기보다 다른 상황을 골라주세요.
